Как добраться
С ТТК (Третье кольцо)
Съезд на Автозаводскую улицу, направление в сторону Даниловской набережной. Въезд в паркинг с правой стороны здания ТРЦ.
Из центра и с набережной
По Автозаводской улице в направлении ТТК. Въезд в паркинг обозначен указателями «РИВЬЕРА» за 300 м.
Навигаторы
Вбивайте в Яндекс.Навигатор или Google Maps: «ТРЦ Ривьера Москва» или «Автозаводская улица 18, Москва».

Возможности паркинга
Зарядка электромобилей
4 зарядные станции на уровне −1. Тип2 и CCS. Оплата через приложение.
Места для МГН
32 специализированных места на уровне −1 ближе к лифтам. Широкий проход.
Для семей с детьми
Выделенные широкие места для семей с детьми на обоих уровнях.
Видеонаблюдение
Вся территория паркинга охвачена видеонаблюдением. Круглосуточная охрана.
Правила парковки
Бесплатно для всех
Парковка абсолютно бесплатна для всех посетителей ТРЦ Ривьера без ограничений по времени стоянки.
Ограничение по высоте
Максимальная высота въезжающих автомобилей — 2,1 м. Микроавтобусы и фургоны — только на наземную стоянку.
Запрещено
Парковка на пожарных проездах, местах для инвалидов без соответствующего разрешения, блокировка выездов.
Вызов охраны
Служба безопасности паркинга работает круглосуточно. Телефон: +7 495 269-99-99 (доб. 5).
